# 俄罗斯方块 · TETRIS

单文件网页版俄罗斯方块，零依赖，双击 `index.html` 就能玩。

## 玩法

| 操作 | 按键 |
|---|---|
| 左右移动 | `←` `→` |
| 软降（加速下落） | `↓` |
| 顺时针旋转 | `↑` 或 `X` |
| 逆时针旋转 | `Z` |
| 硬降（瞬间落地） | `空格` |
| 暂存 / 取出 | `C` |
| 暂停 / 继续 | `P` |
| 重新开始 | `R` |

## 手机操作

- **轻点棋盘** → 旋转
- **左右滑动** → 移动
- **向下滑动** → 软降
- **向上滑动** → 硬降

## 实现了什么

- **SRS 标准旋转系统**：带完整踢墙表（wall kick），贴墙或贴方块时旋转会自动平移，是主流俄罗斯方块的手感
- **7-bag 随机**：每 7 个方块保证 I/J/L/O/S/T/Z 各出现一次，不会连续来一堆 S/Z
- **幽灵块**：半透明轮廓显示落点预览
- **暂存（Hold）**：每块只能存一次，防止无限换块
- **锁定延迟 500ms**：方块落地后有缓冲时间微调位置，最多可重置 15 次
- **DAS/ARR 自动重复**：按住方向键会先停顿再连续移动，手感接近街机
- **计分系统**：消 1/2/3/4 行分别得 100/300/500/800 分，乘当前等级；连续消四行有 Back-to-Back 1.5 倍加成；连击额外加分；软降每格 +1，硬降每格 +2
- **等级系统**：每消 10 行升一级，下落速度逐级加快（共 20 档）
- **响应式布局**：桌面端侧栏在右，窄屏自动堆叠到下方
- **高 DPI 支持**：Retina 屏下清晰不模糊
- **切走页面自动暂停**，避免回来时已经堆满
